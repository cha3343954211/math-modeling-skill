# Stage 5: 封箱复现质检、匿名合规与材料打包 (70~72h)

> **阶段定位**：最后 2 小时的决胜封箱阶段。坚决杜绝“程序跑不通直接被专家降档”或“泄露个人信息被取消成绩”的致命违规。在独立干净目录下执行全量一键复跑测试，完成严格匿名扫描与支撑材料标准化打包。

---

## 1. 阶段目标与准入/准出条件

- **输入依赖**：编译生成的 `paper.pdf`、全量源代码、处理后数据与配置文件。
- **准出交付物**：
  1. `review_checklist.md`（最终质量审查报告）
  2. `reproduction_test_report.md`（干净环境一键复跑验证报告）
  3. `supporting_materials.zip`（规范命名的支撑材料压缩包）
  4. 最终提交确认单与 MD5 校验码
- **人机审批点**：`[CP5 审批点]` 队长终审签字、确认提交系统要求无误后封箱。

---

## 2. 封箱前“四大硬核质检”

### 2.1 干净环境全量一键复跑 (Reproduction Test)
在独立临时目录中解压代码包，执行自动化测试脚本 `test_reproduction.py`：
- [ ] 验证所有数据处理、求解计算、图表绘制从头至尾顺利运行，零报错；
- [ ] 验证运行新生成的图表与论文 PDF 中的图表 100% 相同；
- [ ] 验证新输出的表格数字与 `frozen_numbers.json` 及论文正文 100% 吻合。

### 2.2 匿名与合规红线大扫描 (Anonymity Audit)
进行全工程正则扫描：
- [ ] 论文 PDF（正文、页眉、页脚、致谢、图表标题）无学校、队员姓名、指导教师姓名；
- [ ] 源码与注释（`.py`, `.m`, `.tex` 等）无包含个人信息的作者注释（如 `@Author: 张三`）；
- [ ] 支撑材料文件夹路径无个人姓名或电脑用户名（如 `C:/Users/张三/` 应替换为相对路径 `./`）；
- [ ] PDF 属性元数据（Title, Author, Creator）已清空。

### 2.3 支撑材料目录树规范 (`supporting_materials_layout_v5_0.md`)
```text
支撑材料/
├── README.md               # 运行环境、依赖包列表与一键运行顺序说明
├── data/
│   ├── raw/                # 只读原始数据
│   └── processed/          # 处理后的中间与最终数据
├── code/                   # 求解核心源码（按 00_audit.py, 01_solve_q1.py ... 编号排序）
└── outputs/
    ├── figures/            # 论文中使用的全部高清矢量图
    └── tables/             # 论文中使用的全部数据表格
```

### 2.4 完整 Review 检查单 (`review_checklist.md`)
按模型合理性、结果正确性、逻辑闭环度、交付完整性逐项打勾确认。
