# CUMCM国赛实战攻略

> 全国大学生数学建模竞赛（CUMCM）备赛与实战完全指南

---

## 一、选题策略

### A题 = 机理/优化/连续型
- **特征**：明确的数学问题，通常有固定模型框架（微分方程、优化模型、连续模型）
- **适合**：有扎实数学功底（微积分、微分方程、最优化理论）的队伍
- **常见题型**：传染病传播模型、最优调度、物理过程模拟
- **建议**：如果团队数学能力强，优先选A题，模型清晰，评委认可度高

### B题 = 综合应用/开放型
- **特征**：需要综合分析，模型灵活，可选方法多，有一定开放性
- **适合**：团队协作好，能灵活运用多种方法的队伍
- **常见题型**：多目标优化、系统设计、策略分析
- **建议**：最受欢迎的题目，竞争最激烈，需要在方法创新上突出

### C题 = 数据分析/统计型
- **特征**：数据量大，需要数据预处理、统计分析、机器学习
- **适合**：编程能力强（Python/R），熟悉数据科学工具的队伍
- **常见题型**：预测模型、分类聚类、相关性分析
- **建议**：适合编程强但数学理论弱的队伍，但要注意不能只做数据分析

### 选题决策流程
```
1. 快速浏览三道题（30min）
2. 标记每道题的关键词
3. 评估团队能力匹配度
4. 检查数据是否完整可获取
5. 确定最终选题
```

## 二、时间管理5阶段（72小时赛期）

| 阶段 | 时间范围 | 任务 | 产出 |
|------|---------|------|------|
| **阶段1：审题** | 0-3h | 通读题目、理解要求、圈定关键词 | 题目分析文档 |
| **阶段2：文献调研** | 3-7h | 检索相关文献、寻找可借鉴方法 | 文献综述摘要 |
| **阶段3：建模求解** | 7-33h | 建立模型、编程求解、结果分析 | 模型代码+结果 |
| **阶段4：论文写作** | 33-66h | 撰写论文、制作图表、润色文字 | 论文初稿 |
| **阶段5：检查修改** | 66-72h | 校对检查、格式调整、摘要精炼 | 最终论文 |

### 关键时间节点
- **前4小时**：必须确定选题和基本思路
- **第10小时**：应有初步模型框架
- **第24小时**：应有初步结果
- **第48小时**：论文主体完成
- **第66小时**：提交前检查

### ⚠️ 常见时间管理陷阱
- ❌ 在阶段1花太多时间犹豫
- ❌ 阶段2文献调研无止境
- ❌ 建模阶段反复推翻重来
- ❌ 论文写作拖到最后几小时
- ❌ 检查阶段发现重大问题

## 三、评分标准详解

### 各部分分值分布（满分100分）

| 评分维度 | 分值范围 | 说明 |
|----------|---------|------|
| **摘要** | 15-20分 | 论文的"门面"，评委第一印象 |
| **建模** | 25-30分 | 核心竞争力，方法的合理性和创新性 |
| **结果** | 15-20分 | 计算结果的准确性和分析深度 |
| **论文** | 15-20分 | 表述清晰、逻辑连贯、格式规范 |
| **创新** | 10-15分 | 方法创新、应用创新、视角创新 |

### 摘要评分要点（15-20分）
- 问题重述是否准确
- 模型方法是否清晰
- 结果是否量化
- 关键结论是否突出
- 字数控制在300-500字

### 建模评分要点（25-30分）
- 问题分析是否到位
- 假设是否合理且必要
- 模型构建是否完整
- 求解方法是否恰当
- 模型检验是否充分

## 四、常见扣分项

### 致命扣分项（-10分以上）
1. **摘要空洞**：只有方法罗列，无具体结果数据
2. **符号混乱**：全文符号不统一，同一变量多种表示
3. **逻辑颠倒**：先写结果再写假设，因果关系混乱
4. **缺乏检验**：模型无灵敏度分析、无误差分析

### 一般扣分项（-3~10分）
5. **图表不规范**：无标题、无坐标轴标签、无单位
6. **参考文献缺失**：无引用或引用格式不统一
7. **语言表达差**：口语化、不专业、错别字多
8. **排版混乱**：页码不连续、公式编号缺失

### 轻微扣分项（-1~3分）
9. **格式不统一**：字号、字体、行距不一致
10. **打印质量差**：图表模糊、打印不清晰

## 五、数据预处理最佳实践

### 缺失值处理决策树
```
缺失值类型判断
├── 完全随机缺失(MCAR)
│   ├── 缺失比例 < 5% → 直接删除
│   ├── 缺失比例 5%-20% → 均值/中位数填充
│   └── 缺失比例 > 20% → 考虑插值或模型预测填充
├── 随机缺失(MAR)
│   ├── 有相关变量 → 多重插补(MICE)
│   └── 无相关变量 → 均值/中位数填充
└── 非随机缺失(MNAR)
    ├── 明确原因 → 基于原因的填补
    └── 原因不明 → 标记为特殊值，后续分析说明
```

### 异常值检测方法
1. **统计方法**：3σ原则、IQR方法、Z-score
2. **可视化方法**：箱线图、散点图、直方图
3. **模型方法**：孤立森林、DBSCAN聚类

### 标准化方法选择
| 方法 | 公式 | 适用场景 |
|------|------|---------|
| Z-score标准化 | (x-μ)/σ | 数据近似正态分布 |
| Min-Max归一化 | (x-min)/(max-min) | 需要保留原始分布形态 |
| RobustScaler | (x-median)/IQR | 存在异常值时 |

### 特征工程清单
- [ ] 数值特征：标准化/归一化
- [ ] 类别特征：独热编码/标签编码
- [ ] 日期特征：提取年/月/日/星期/季度
- [ ] 文本特征：TF-IDF/词嵌入
- [ ] 统计特征：均值、方差、偏度、峰度

### EDA（探索性数据分析）清单
1. 数据概览：shape、dtypes、describe
2. 缺失值统计：各列缺失比例
3. 分布分析：数值特征直方图、类别特征频率图
4. 相关性分析：相关系数矩阵、热力图
5. 时序特征：趋势、季节性、周期性

## 六、评委审阅优先级

### 评委阅读顺序（推测）
```
1. 摘要（决定是否继续深入）
2. 问题重述与分析（确认理解题意）
3. 模型建立（核心评分点）
4. 模型求解与结果（验证模型有效性）
5. 模型检验与分析（体现严谨性）
6. 结论与建议（总结升华）
7. 图表（辅助理解）
8. 参考文献（学术规范）
```

### 评委关注重点
- **前2分钟**：摘要质量决定论文能否进入"优秀"候选
- **前10分钟**：快速浏览结构，判断论文完整性
- **深度阅读**：重点看建模部分的方法创新和求解过程

### 提高评分的策略
1. 摘要必须包含：问题、方法、结果、结论四要素
2. 图表要专业美观，有完整标注
3. 模型要有创新点，哪怕是微小的改进
4. 结果分析要深入，不能只展示数字
5. 论文结构要清晰，逻辑链条完整

## 七、赛前准备清单

### 团队分工建议
| 角色 | 职责 | 核心技能 |
|------|------|---------|
| 建模手 | 问题分析、模型构建 | 数学建模、论文写作 |

- **编程**：Python + NumPy/SciPy/Pandas/Scikit-learn/Matplotlib

- **文献**：知网、Web of Science、Google Scholar
- **绘图**：MATLAB、Python Matplotlib/Seaborn、Visio

### 知识储备
- 常用数学模型：微分方程、线性规划、整数规划、图论
- 常用算法：遗传算法、模拟退火、粒子群优化、神经网络
- 常用方法：回归分析、时间序列、聚类分析、主成分分析
