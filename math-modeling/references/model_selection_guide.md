# 模型选择决策树参考指南

> 本文档为数学建模竞赛中模型选择的完整决策指南，帮助快速定位适合的模型并进行对比验证。

---

## 1. 总体原则：先定 Baseline，再定主模型

### 1.1 Baseline 的作用
- **提供对比基准**：所有后续模型的效果都需要与 baseline 对比
- **验证数据质量**：如果 baseline 效果很差，说明数据可能有问题
- **确保可运行**：baseline 必须是最简单、最确定能跑通的模型

### 1.2 选择顺序
```
数据探索 → 数据清洗 → Baseline 模型 → 主模型 → 对比分析 → 验证与灵敏度
```

### 1.3 Baseline 要求
| 要求 | 说明 |
|------|------|
| 简单 | 优先使用经典统计方法或规则型方法 |
| 可运行 | 确保在有限时间内能出结果 |
| 有物理/数学含义 | 结果能解释，不是黑箱 |
| 快速 | 编码时间短，适合竞赛时间约束 |

## 2. 问题类型 → 模型速查表

| 问题类型 | Baseline 模型 | 主模型推荐 | 验证方法 |
|---------|--------------|-----------|---------|
| **评价类** | 加权求和法 | TOPSIS + 熵权法 / AHP + 模糊综合评价 | 指标灵敏度分析、主观客观一致性检验 |
| **预测类** | 线性回归 | 灰色GM(1,1) / ARIMA / LSTM | MAE、RMSE、R²对比 |
| **优化类** | 线性规划（单纯形法） | 遗传算法 / 模拟退火 / 粒子群算法 | 最优值收敛曲线、灵敏度分析 |
| **机理类** | 常微分方程（ODE） | PDE / 多尺度建模 | 模型残差分析、参数灵敏度 |
| **分类/聚类** | 逻辑回归 / K-means | SVM / 随机森林 / XGBoost | 混淆矩阵、AUC、F1 |
| **图论/路径** | Dijkstra算法 | 遗传算法 / 蚁群算法 / 网络流 | 路径长度对比、计算时间 |
| **仿真类** | 蒙特卡洛模拟 | 元胞自动机 / Agent-Based Model | 多次模拟统计量、置信区间 |
| **数据分析类** | 描述统计 + 相关分析 | PCA + 回归 / 聚类分析 | KMO检验、方差解释率 |
| **混合类** | 按子问题分别建 baseline | 多模型耦合 / 级联模型 | 各子问题验证 + 系统验证 |

## 3. 各题型详细决策树

### 3.1 评价类问题

```
评价类问题
├── 指标可量化？
│   ├── 是 → 指标之间有相互关联？
│   │   ├── 是 → AHP + TOPSIS（AHP处理关联，TOPSIS排序）
│   │   └── 否 → 熵权法 + TOPSIS（客观赋权）
│   └── 否（有主观成分）→ 层次分析法(AHP) + 模糊综合评价
└── 需要多方案对比？
    ├── 是 → TOPSIS法（距离理想解最近的方案最优）
    └── 否 → 灰色关联分析
```

**典型场景**：
- 城市竞争力排名 → 熵权法 + TOPSIS
- 供应商选择 → AHP + TOPSIS
- 健康状况评估 → 模糊综合评价

### 3.2 预测类问题

```
预测类问题
├── 数据量？
│   ├── 小数据（<50个样本）→ 灰色GM(1,1)
│   │   └── 有季节性？→ GM(1,1) + 傅里叶修正
│   ├── 中等数据（50-500）→ 时间序列方法
│   │   ├── 有季节性？→ SARIMA
│   │   ├── 单变量？→ ARIMA
│   │   └── 多变量？→ VAR / 协整分析
│   └── 大数据（>500）→ 深度学习
│       ├── 单变量 → LSTM / GRU
│       ├── 多变量 → Transformer / 时序卷积网络
│       └── 有空间信息？→ GNN + LSTM
└── 需要可解释性？
    ├── 是 → 灰色模型 / ARIMA
    └── 否 → LSTM / Transformer
```

**典型场景**：
- 人口预测（少量数据）→ GM(1,1)
- 股票价格预测 → ARIMA + LSTM对比
- 传染病传播预测 → SIR机理模型 + LSTM混合

### 3.3 优化类问题

```
优化类问题
├── 目标函数和约束？
│   ├── 线性 + 连续变量 → 单纯形法 / 线性规划
│   ├── 线性 + 整数变量 → 整数规划 / 分支定界法
│   ├── 非线性但可导 → 梯度下降 / 内点法
│   ├── 不可导 / 离散 / 多峰 → 启发式算法
│   │   ├── 全局搜索 → 遗传算法(GA)
│   │   ├── 邻域搜索 → 模拟退火(SA)
│   │   ├── 群体智能 → 粒子群算法(PSO)
│   │   └── 组合优化 → 蚁群算法(ACO) / 遗传算法
│   └── 有约束？→ 罚函数法 / 拉格朗日乘子法
├── 变量数量？
│   ├── <10 → 精确算法（穷举 / 动态规划）
│   ├── 10-100 → 启发式算法
│   └── >100 → 元启发式 / 深度强化学习
└── 多目标？
    ├── 是 → NSGA-II / 多目标粒子群(MOPSO)
    └── 否 → 单目标优化
```

**典型场景**：
- 资源分配（线性）→ 线性规划
- 车辆路径问题(VRP) → 遗传算法 / 蚁群算法
- 函数优化（多峰）→ 遗传算法 + 模拟退火混合

### 3.4 分类/聚类问题

```
分类/聚类问题
├── 有标签数据？
│   ├── 是（分类问题）
│   │   ├── 数据量 < 100 → SVM / KNN
│   │   ├── 数据量 100-10000 → 随机森林 / XGBoost
│   │   ├── 数据量 > 10000 → 深度学习（DNN / CNN / Transformer）
│   │   └── 类别不平衡？→ SMOTE + 集成学习
│   └── 否（聚类问题）
│       ├── 数据量 < 200 → K-means / 层次聚类
│       ├── 数据量 > 200 → DBSCAN / 高斯混合模型(GMM)
│       ├── 维度高 → PCA降维 + 聚类
│       └── 非球形分布 → 谱聚类 / DBSCAN
└── 需要可解释性？
    ├── 是 → 决策树 / 逻辑回归
    └── 否 → 随机森林 / XGBoost / 神经网络
```

**典型场景**：
- 客户细分 → K-means（简单）+ DBSCAN（复杂）
- 图像分类 → CNN
- 文本情感分析 → LSTM / Transformer

### 3.5 图论/路径问题

```
图论/路径问题
├── 问题类型？
│   ├── 最短路径 → Dijkstra / Bellman-Ford / Floyd
│   ├── 最大流 → Ford-Fulkerson / 割集法
│   ├── 最小生成树 → Kruskal / Prim
│   ├── 旅行商问题(TSP) → 遗传算法 / 蚁群算法
│   ├── 车辆路径问题(VRP) → 遗传算法 / 粒子群算法
│   └── 网络设计 → 整数规划 / 启发式算法
├── 规模？
│   ├── 节点 < 100 → 精确算法
│   ├── 节点 100-1000 → 启发式算法
│   └── 节点 > 1000 → 近似算法 / 启发式算法
└── 有动态变化？
    ├── 是 → 在线算法 / 动态规划
    └── 否 → 静态算法
```

### 3.6 仿真类问题

```
仿真类问题
├── 涉及随机性？
│   ├── 是 → 蒙特卡洛模拟
│   └── 否 → 确定性仿真
├── 涉及个体行为？
│   ├── 是 → Agent-Based Model (ABM)
│   └── 否 → 传统仿真模型
├── 涉及空间分布？

│   └── 否 → 系统动力学(SD)

    └── 否 → 离散事件仿真

### 3.7 数据分析类

```
数据分析类

│   ├── 是 → 描述统计 + 可视化
│   └── 否 → 深度分析
├── 降维需求？
│   ├── 是 → PCA / t-SNE / UMAP
│   └── 否 → 直接分析

## 4. 模型选择核心原则

### 4.1 先简后繁
- 先用简单模型（线性回归、灰色模型）建立 baseline
- 逐步增加复杂度，每一步都要验证是否有显著提升
- **不要一上来就用深度学习**，除非数据量足够且问题确实复杂

### 4.2 可解释优先
- 数学建模竞赛重视模型的**数学原理和可解释性**
- 优先选择有明确数学公式支撑的模型
- 黑箱模型（如深度学习）需要配合 SHAP/LIME 等解释工具

### 4.3 多模型对比
- 至少准备 2-3 个模型进行对比
- 从不同角度（精度、计算效率、可解释性）进行评价
- **创新点**通常来自模型对比后的改进

### 4.4 创新点明确
- 创新点不是堆砌复杂模型
- 可能的创新方向：
  - 改进现有模型的某个环节
  - 组合两个模型的各自优点
  - 针对具体问题进行模型定制
  - 提出新的评价指标或验证方法

## 5. 结果验证与灵敏度分析

### 5.1 验证指标

#### 回归/预测类
| 指标 | 公式/说明 | 适用场景 |
|------|----------|---------|
| MAE | $\frac{1}{n}\sum|y_i - \hat{y}_i|$ | 衡量平均绝对误差 |
| RMSE | $\sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}$ | 对大误差敏感 |
| MAPE | $\frac{1}{n}\sum|\frac{y_i - \hat{y}_i}{y_i}| \times 100\%$ | 相对误差，便于比较 |
| R² | $1 - \frac{SS_{res}}{SS_{tot}}$ | 模型解释力 |

#### 分类类
| 指标 | 说明 | 适用场景 |
|------|------|---------|
| 准确率(Accuracy) | 正确预测比例 | 类别平衡时 |
| 精确率(Precision) | 预测为正中实际为正的比例 | 关注误报时 |
| 召回率(Recall) | 实际为正中预测为正的比例 | 关注漏报时 |
| F1分数 | 精确率和召回率的调和平均 | 类别不平衡时 |
| AUC-ROC | ROC曲线下面积 | 综合评估分类性能 |

#### 评价类
| 指标 | 说明 |
|------|------|
| 一致性比率(CR) | AHP中判断矩阵的一致性检验 |
| Kendall协调系数 | 多个评价者的一致性 |
| Spearman等级相关 | 排序结果的相关性 |

### 5.2 残差分析
```
残差分析步骤：
1. 绘制残差 vs 拟合值图
   - 理想状态：残差随机分布在0附近，无明显模式
   - 有模式 → 模型可能遗漏了重要变量

2. 残差正态性检验
   - Q-Q图：点应近似在对角线上
   - Shapiro-Wilk检验：p > 0.05 表示正态

3. 残差自相关检验
   - Durbin-Watson检验：值接近2表示无自相关
   - ACF图：滞后阶数的自相关系数应在置信区间内
```

### 5.3 灵敏度分析方法

#### 方法一：单因素分析
```
固定其他参数不变，改变某一参数（如±10%、±20%、±50%），
观察输出结果的变化。
```
- **优点**：简单直观
- **缺点**：无法反映参数交互作用
- **适用**：参数较少（<5个）时

#### 方法二：Sobol指数分析
```
计算每个参数对输出方差的贡献比例（一阶指数），
以及参数交互的贡献（高阶指数）。
```
- **优点**：能量化参数重要性排序
- **缺点**：计算量大（需要大量样本）
- **适用**：参数较多时

#### 方法三：蒙特卡洛灵敏度分析
```
在参数的合理范围内随机抽样，统计输出的分布特征。
```
- **优点**：可以考虑参数的不确定性
- **缺点**：需要明确定义参数分布
- **适用**：有先验信息时

## 9. 注意事项与陷阱

### 常见错误
1. **数据泄露**：使用了测试集信息训练模型
2. **过拟合**：模型在训练集上表现完美，测试集上表现差
3. **忽略baseline**：直接用复杂模型，无法证明其有效性
4. **只看精度**：忽略可解释性、计算效率等维度
5. **创新点不明确**：堆砌模型但没有实质性改进

### 提分技巧
1. **图表美观**：使用 matplotlib/seaborn 绘制专业图表
2. **公式规范**：使用 LaTeX 排版数学公式
3. **对比充分**：至少3个模型对比，从多维度评价
4. **灵敏度必做**：几乎所有题目都需要灵敏度分析
5. **结合实际**：模型结果要与实际背景结合解释
