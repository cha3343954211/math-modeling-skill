# 模型选择决策树参考指南

> 本文档为数学建模竞赛中模型选择的完整决策指南，帮助快速定位适合的模型并进行对比验证。

---

## 1. 总体原则：先定 Baseline，再定主模型

### 1.1 Baseline 的作用
- **提供对比基准**：所有后续模型的效果都需要与 baseline 对比
- **验证数据质量**：如果 baseline 效果很差，说明数据可能有问题
- **确保可运行**：baseline 必须是最简单、最确定能跑通的模型

### 1.2 选择顺序
```
数据探索 → 数据清洗 → Baseline 模型 → 主模型 → 对比分析 → 验证与灵敏度
```

### 1.3 Baseline 要求
| 要求 | 说明 |
|------|------|
| 简单 | 优先使用经典统计方法或规则型方法 |
| 可运行 | 确保在有限时间内能出结果 |
| 有物理/数学含义 | 结果能解释，不是黑箱 |
| 快速 | 编码时间短，适合竞赛时间约束 |

## 2. 问题类型 → 模型速查表

| 问题类型 | Baseline 模型 | 主模型推荐 | 验证方法 |
|---------|--------------|-----------|---------|
| **评价类** | 等权/规则型综合评分 | 经指标审计后的 TOPSIS、AHP、熵权/CRITIC 或组合赋权 | 权重、归一化与排名稳定性；指标冗余检查 |
| **预测类** | 持久性/季节性持久性、简单回归 | 经时间结构诊断后的指数平滑、ARIMA/SARIMA、动态回归、机理或深度时序模型 | 时间外/滚动误差、误差分布、基线对照 |
| **优化类** | 规则策略、LP/MILP或其松弛（视结构） | 精确优化、分解法、动态规划或经对照验证的启发式 | 约束满足、求解器状态/缺口、规则/下界/小规模精确对照 |
| **机理类** | 最简守恒/ODE模型 | PDE、多尺度或数据同化模型 | 量纲、边界条件、参数可识别性、残差/灵敏度 |
| **分类/聚类** | 多数类/逻辑回归；K-means等可解释聚类 | 树模型、核方法、密度/层次/谱聚类、深度模型（条件满足时） | 切分协议、F1/PR-AUC或簇稳定性与可解释性 |
| **图论/路径** | 标准精确算法、规则路径 | 网络流/MILP、分解法或启发式 | 可行性、运行时间、下界/小规模精确对照 |
| **仿真类** | 可解释的确定性或简单随机仿真 | 元胞自动机 / Agent-Based Model / 离散事件或系统动力学 | 校准、重复运行、置信区间、情景边界 |
| **数据分析类** | 描述统计 + 可视化 | PCA + 回归 / 聚类 / 因果识别方法（条件满足时） | 数据口径、稳健性、识别假设或方差解释 |
| **混合类** | 按子问题分别建 baseline | 多模型耦合 / 级联模型 | 各子问题验证 + 系统验证 |

## 3. 各题型详细决策树

### 3.1 评价类问题

```
评价类问题
├── 指标定义、方向和单位清楚吗？
│   ├── 否 → 先重构指标与数据口径，不能直接赋权
│   └── 是 → 检查缺失、极端值、相关性与重复计权
├── 指标高度相关或概念重复？
│   ├── 是 → 合并/删减指标，或用 PCA/因子分析形成维度后再评价
│   └── 否 → 选择权重来源
│       ├── 有可信专家判断且可通过一致性检验 → AHP/德尔菲等主观权重
│       ├── 主要依赖观测数据差异 → 熵权、CRITIC等客观权重
│       └── 两类信息均有 → 明确组合权重公式、比例和理由
└── 需要方案排序？
    ├── 是 → TOPSIS、VIKOR、PROMETHEE等，并报告归一化/距离度量/权重敏感性
    └── 否 → 加权评分、灰色关联或分层评价（视问题含义）
```

**关键说明**：AHP用于结构化专家判断和权重确定，**不用于消除统计关联或共线性**。TOPSIS等排序方法的结果会受归一化、距离度量和权重影响，必须做扰动/替代方案下的排名稳定性检查。

**典型场景**：
- 城市竞争力排名 → 指标审计 + 客观/组合赋权 + TOPSIS，并检验前列排名稳定性
- 供应商选择 → 有专家偏好时使用 AHP/组合权重 + 排序方法；无专家依据时避免伪造主观判断
- 健康状况评估 → 指标定义 + 模糊综合评价或分层评分，并说明隶属函数来源

### 3.2 预测类问题

```
预测类问题
├── 预测时点、预测步长和可用信息是否明确？
│   ├── 否 → 先定义业务决策与预测协议
│   └── 是 → 检查时间顺序、频率、缺失、结构突变、季节性及外生变量
├── 是否存在可复现的时间外验证区间？
│   ├── 是 → 使用滚动/扩展窗口验证，先建立朴素基线（持久性、季节性持久性等）
│   └── 否 → 明确只能做拟合/情景分析，不能夸大为预测精度
├── 候选模型
│   ├── 稳定、样本有限、趋势明确 → 指数平滑、回归、GM(1,1)（需检验适用条件）
│   ├── 单变量时序且有自相关/季节性 → ARIMA/SARIMA、状态空间模型
│   ├── 有可信外生变量 → 动态回归、VAR等（避免未来不可得变量）
│   └── 非线性且数据、验证与计算资源充足 → 树模型、深度时序模型；必须与简单模型对照
└── 需要可解释性？
    ├── 是 → 优先回归、指数平滑、ARIMA或机理模型
    └── 否 → 仍须报告外推稳定性和误差分布，不能仅报训练集表现
```

> 样本量只提示过拟合与计算预算风险，**不能单独决定模型**。GM(1,1)不因“小样本”自动适用：需检查非负性、累加后趋势与级比等条件；深度学习也不因“大样本”自动优于统计或机理模型。

**典型场景**：
- 短期且趋势较稳定的序列 → 持久性/指数平滑 baseline，再比较满足条件的 GM(1,1) 或回归模型
- 季节性需求预测 → 季节性朴素法 baseline + SARIMA/状态空间模型，采用滚动验证
- 传染病传播预测 → 机理模型与数据驱动模型可比较，但必须区分情景推演与真实外推预测

### 3.3 优化类问题

```
优化类问题
├── 目标、变量、单位和约束来源是否明确？
│   ├── 否 → 先完成问题规格和量纲/口径检查
│   └── 是 → 判断结构与求解规模
├── 结构可被线性/整数线性表达且可在时间预算内求解？
│   ├── 是 → 优先 LP/MILP/网络流等精确模型；报告求解器状态、最优性缺口和约束满足
│   └── 否 → 考虑非线性规划、动态规划、分解法或启发式/元启发式
├── 非凸、离散或组合复杂？
│   ├── 是 → 设计可行解构造 + 局部搜索/GA/SA/ACO等，并与简单规则及可得下界/小规模精确解比较
│   └── 否 → 使用相应连续优化或约束优化方法
└── 多目标？
    ├── 是 → 明确偏好信息，使用 ε-约束、加权法或 Pareto 方法；报告权重/阈值敏感性
    └── 否 → 单目标求解并报告目标值与可行性
```

> 变量数或节点数只能作为计算预算提示，**不能单独规定使用精确法或启发式**。启发式算法输出应表述为“已找到的可行近似解”；除非有严格证明或求解器证书，不得宣称全局最优。

**典型场景**：
- 资源分配 → 先建 LP/MILP baseline，检查求解状态和约束；
- VRP/TSP → 小规模实例用精确方法校验或给下界，大规模再使用启发式并报告重复运行与缺口；
- 多目标调度 → 先说明决策者偏好或展示 Pareto 前沿，再提出推荐方案。

### 3.4 分类/聚类问题

```
分类/聚类问题
├── 有标签、标签质量与预测时点是否明确？
│   ├── 是 → 先设定分层/时间一致的验证划分与简单 baseline（多数类、逻辑回归、树模型）
│   └── 否 → 明确为聚类/探索任务，先定义距离、变量尺度和“簇有何业务含义”
├── 分类任务
│   ├── 类别不平衡 → 以 PR-AUC、F1、召回等匹配任务损失的指标为主；重采样仅在训练折内进行
│   ├── 表格数据 → 比较逻辑回归、决策树/随机森林、梯度提升等，兼顾校准与解释
│   └── 图像/文本/序列 → 仅在预训练资源、数据与验证充分时考虑深度模型
└── 聚类任务
    ├── 近似球状、需明确分群数 → K-means/GMM 等候选
    ├── 非球形或含噪声 → DBSCAN、谱聚类、层次聚类等候选
    └── 高维 → 先做尺度处理；降维用于可视化或建模时须报告其对稳定性的影响
```

> 样本数量不是分类器或聚类器的选择开关。模型选择还取决于特征类型、类别分布、距离结构、标签质量、验证资源和解释需求。聚类没有天然“真值”时，轮廓系数只能作为参考，还应检查稳定性及簇的实际可解释性。

**典型场景**：
- 客户细分 → 比较 K-means、GMM、层次/密度聚类，并报告不同初始化和样本扰动下的稳定性；
- 风险分类 → 使用时间一致或分层验证，报告阈值下的误报/漏报代价；
- 图像/文本分类 → 与可行的预训练或线性 baseline 对照，避免只报告训练集准确率。

### 3.5 图论/路径问题

```
图论/路径问题
├── 图的节点、边、方向、权重、时间依赖与可达性是否定义清楚？
│   ├── 否 → 先完成网络构建与单位/数据审计
│   └── 是 → 按目标与结构选模型
├── 单源/多源最短路、最大流、最小生成树等标准问题 → 使用相应精确算法并检查输入假设
├── 路径/车辆路径/网络设计含容量、时间窗、整数决策或多目标 → 优先形成 MILP/网络流/列生成等可解释基线
├── 精确求解超出时间预算或问题结构复杂 → 使用启发式/元启发式，并和规则策略、下界或小规模精确解比较
└── 网络动态变化 → 明确静态近似的边界，或采用滚动重优化/时变网络模型
```

> 节点数本身不决定是否能精确求解；稀疏性、约束结构、求解器、时间预算和最优性要求同样关键。近似算法须报告可行性、运行时间、重复运行差异和对照证据。

### 3.6 仿真类问题

```
仿真类问题
├── 涉及随机性？
│   ├── 是 → 蒙特卡洛模拟
│   └── 否 → 确定性仿真
├── 涉及个体行为？
│   ├── 是 → Agent-Based Model (ABM)
│   └── 否 → 传统仿真模型
├── 涉及空间分布？
│   ├── 是 → 元胞自动机(CA) / 有限元方法(FEM)
│   └── 否 → 系统动力学(SD)
└── 涉及连续过程？
    ├── 是 → 偏微分方程(PDE) / 有限差分
    └── 否 → 离散事件仿真
```

### 3.7 数据分析类

```
数据分析类
├── 数据探索？
│   ├── 是 → 描述统计 + 可视化
│   └── 否 → 深度分析
├── 降维需求？
│   ├── 是 → PCA / t-SNE / UMAP
│   └── 否 → 直接分析
├── 异常检测？
│   ├── 是 → Isolation Forest / LOF / DBSCAN
│   └── 否 → 正常分析流程
└── 因果推断？
    ├── 是 → 工具变量法 / 双重差分(DID) / 断点回归(RDD)
    └── 否 → 相关分析 / 回归分析
```

## 4. 模型选择核心原则

### 4.1 先简后繁
- 先用简单模型（线性回归、灰色模型）建立 baseline
- 逐步增加复杂度，每一步都要验证是否有显著提升
- **不要一上来就用深度学习**，除非数据量足够且问题确实复杂

### 4.2 可解释优先
- 数学建模竞赛重视模型的**数学原理和可解释性**
- 优先选择有明确数学公式支撑的模型
- 黑箱模型（如深度学习）需要配合 SHAP/LIME 等解释工具

### 4.3 多模型对比
- 至少准备 2-3 个模型进行对比
- 从不同角度（精度、计算效率、可解释性）进行评价
- **创新点**通常来自模型对比后的改进

### 4.4 创新点明确
- 创新点不是堆砌复杂模型
- 可能的创新方向：
  - 改进现有模型的某个环节
  - 组合两个模型的各自优点
  - 针对具体问题进行模型定制
  - 提出新的评价指标或验证方法

## 5. 结果验证与灵敏度分析

### 5.1 验证指标

#### 回归/预测类
| 指标 | 公式/说明 | 适用场景 |
|------|----------|---------|
| MAE | $\frac{1}{n}\sum|y_i - \hat{y}_i|$ | 衡量平均绝对误差 |
| RMSE | $\sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}$ | 对大误差敏感 |
| MAPE | $\frac{1}{n}\sum|\frac{y_i - \hat{y}_i}{y_i}| \times 100\%$ | 相对误差，便于比较 |
| R² | $1 - \frac{SS_{res}}{SS_{tot}}$ | 模型解释力 |

#### 分类类
| 指标 | 说明 | 适用场景 |
|------|------|---------|
| 准确率(Accuracy) | 正确预测比例 | 类别平衡时 |
| 精确率(Precision) | 预测为正中实际为正的比例 | 关注误报时 |
| 召回率(Recall) | 实际为正中预测为正的比例 | 关注漏报时 |
| F1分数 | 精确率和召回率的调和平均 | 类别不平衡时 |
| AUC-ROC | ROC曲线下面积 | 综合评估分类性能 |

#### 评价类
| 指标 | 说明 |
|------|------|
| 一致性比率(CR) | AHP中判断矩阵的一致性检验 |
| Kendall协调系数 | 多个评价者的一致性 |
| Spearman等级相关 | 排序结果的相关性 |

### 5.2 残差分析
```
残差分析步骤：
1. 绘制残差 vs 拟合值图
   - 理想状态：残差随机分布在0附近，无明显模式
   - 有模式 → 模型可能遗漏了重要变量

2. 残差正态性检验
   - Q-Q图：点应近似在对角线上
   - Shapiro-Wilk检验：p > 0.05 表示正态

3. 残差自相关检验
   - Durbin-Watson检验：值接近2表示无自相关
   - ACF图：滞后阶数的自相关系数应在置信区间内
```

### 5.3 灵敏度分析方法

#### 方法一：单因素分析
```
固定其他参数不变，改变某一参数（如±10%、±20%、±50%），
观察输出结果的变化。
```
- **优点**：简单直观
- **缺点**：无法反映参数交互作用
- **适用**：参数较少（<5个）时

#### 方法二：Sobol指数分析
```
计算每个参数对输出方差的贡献比例（一阶指数），
以及参数交互的贡献（高阶指数）。
```
- **优点**：能量化参数重要性排序
- **缺点**：计算量大（需要大量样本）
- **适用**：参数较多时

#### 方法三：蒙特卡洛灵敏度分析
```
在参数的合理范围内随机抽样，统计输出的分布特征。
```
- **优点**：可以考虑参数的不确定性
- **缺点**：需要明确定义参数分布
- **适用**：有先验信息时

## 7. 常见模型的Python/MATLAB实现要点

### Python 快速实现

```python
# 灰色GM(1,1)
# pip install grey
from grey import GM1
gm = GM1(data)  # data为原始数据序列
result = gm.predict(n)  # 预测n个值

# TOPSIS
# pip install topsis
import numpy as np
from topsis import topsis

# 熵权法
# pip install entropy-weight
from entropy_weight import entropy_weight

# 遗传算法
# pip install pymoo
from pymoo.algorithms.moo.nsga2 import NSGA2
from pymoo.optimize import minimize

# ARIMA
```

## 9. 注意事项与陷阱

### 常见错误
1. **数据泄露**：使用了测试集信息训练模型
2. **过拟合**：模型在训练集上表现完美，测试集上表现差
3. **忽略baseline**：直接用复杂模型，无法证明其有效性
4. **只看精度**：忽略可解释性、计算效率等维度
5. **创新点不明确**：堆砌模型但没有实质性改进

### 提分技巧
1. **图表美观**：使用 matplotlib/seaborn 绘制专业图表
2. **公式规范**：使用 LaTeX 排版数学公式
3. **对比充分**：至少3个模型对比，从多维度评价
4. **灵敏度必做**：几乎所有题目都需要灵敏度分析
5. **结合实际**：模型结果要与实际背景结合解释
