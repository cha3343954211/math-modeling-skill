## 一、 国赛 C 题（数据驱动与运筹决策）专家评审 5 大铁律

1. **非大数据慎用大数据预处理套路**：
   - 绝对禁止无脑“均值填补/KNN填补/插值填充/一律剔除异常值”。
   - 在真实业务数据中，“缺失”或“零值”往往具有关键业务意义（例如蔬菜某天销售为空代表当天未进货或售罄，盲目填补等于无中生有、篡改赛题本质；NIPT 错漏数据可通过生理公式反推，不可一删了之）。
2. **严禁在连续/离散优化中盲目滥用启发式算法 (GA / PSO / SA)**：
   - 对于农作物种植（2024-C）、订购运输（2021-C）、蔬菜定价补货（2023-C）等复杂的运筹优化问题，**必须通过辅助变量与线性化技巧转化为精确数学规划（MILP / MINLP）**。
   - 盲目套用遗传算法、粒子群等启发式算法通常会导致严重违背约束、计算不可行或收敛到劣解，在专家评审中会被直接判定为“非有效可行算法”。
3. **小样本成分数据必须进行流形变换 (CLR)**：
   - 古代玻璃（2022-C）等成分数据属于**单形空间（Simplex）**，其各组分之和恒为 $100\%$，存在伪相关与闭合效应。必须先做**中心对称对数比变换（CLR）**映射到欧氏空间后才能做多元统计分析。
4. **小样本判别严防机器学习过拟合**：
   - 样本量只有几十至几百个时（如 2025-C 女胎异常判定、2022-C 玻璃亚分类），深度学习和复杂机器学习极易过拟合，经典多元统计方法（Fisher 判别、Logistic 回归、贝叶斯判别、条件有序聚类）才是正统。
5. **警惕“伪相关”与统计尺度陷阱**：
   - 蔬菜（2023-C）在按天统计时相关系数接近于 0（$10^{-27}\sim 10^{-29}$），但按周、月、季汇总后存在强季节性与品类协同规律。必须依据业务机理选择正确的统计时间尺度。

## 二、 历年 C 题（2020~2025）核心模型机理与硬核推导

### 1. 2025-C：NIPT 时点选择与胎儿异常判定（医学统计与风险优化）
- **核心数据属性**：高 BMI 孕妇实测纵向数据，男胎 Y 染色体浓度达标门槛 $\ge 4\%$。
- **数学建模要点**：
  1. **Y 染色体浓度相依关系**：采用**混合效应多元非线性回归**（Mixed-Effects Regression）捕捉孕周、BMI、身高、年龄的固定效应与孕妇个体随机效应：
     $$Y_{it} = \beta_0 + \beta_1 \text{GA}_{it} + \beta_2 \text{BMI}_i + \beta_3 (\text{GA}_{it} \times \text{BMI}_i) + u_i + \varepsilon_{it}$$
  2. **BMI 最佳分组模型**：采用**有序样本聚类法（Fisher 最优分割法）**，临床基准分为 $[20,28), [28,32), [32,36), [36,40), 40\text{以上}$。
  3. **潜在风险最小化目标函数**：
     $$\min \text{Risk} = \sum_{k} w_k \cdot P(\text{浓度未达标} \mid t_k, \text{BMI}_k) + C(\text{错过最佳流产周数风险})$$
  4. **女胎判别**：经典小样本非参数统计判别分析（X 染色体浓度分布检验）。

### 2. 2024-C：农作物种植策略（大规模混合整数规划与精确线性化）
- **核心业务拆解**：必须将**粮食作物（平旱地/梯田/山坡地单季）**与**大棚蔬菜/食用菌**拆分为两个子系统独立规划，大幅降低求解维度。
- **超产滞销与降价 50% 的精确线性化数学模型**：
  设 $x_{ij}^{(k)}$ 为第 $k$ 年第 $i$ 地块种植第 $j$ 种作物的亩数，$s_{ij}$ 为亩产量，$p_j$ 为原单价，$c_j$ 为亩成本，$S_j$ 为预期额定销量。

#### 情况 1：超产部分完全滞销（浪费）
目标收益：
$$\max P = \sum_{k=1}^7 \sum_{j=1}^{15} \left[ p_j Q_j^{(k)} - \sum_{i=1}^{26} c_j x_{ij}^{(k)} \right]$$
其中实际计费销量 $Q_j^{(k)} = \min\left[\sum_{i=1}^{26} s_{ij} x_{ij}^{(k)}, S_j\right]$。  
**精确线性化约束**：
$$Q_j^{(k)} \le \sum_{i=1}^{26} s_{ij} x_{ij}^{(k)}, \quad Q_j^{(k)} \le S_j, \quad Q_j^{(k)} \ge 0$$

#### 情况 2：超产部分降价 50% 出售
引入有效销量 $Q_j^{(k)}$ 与超产量 $R_j^{(k)}$：
$$\text{总产出} Y_j^{(k)} = \sum_{i=1}^{26} s_{ij} x_{ij}^{(k)}$$
$$R_j^{(k)} = \max\left[Y_j^{(k)} - S_j, 0\right] \iff R_j^{(k)} \ge Y_j^{(k)} - S_j, \quad R_j^{(k)} \ge 0$$
实际收益目标函数：
$$\max P = \sum_{k=1}^7 \sum_{j=1}^{15} \left[ p_j \cdot \min(Y_j^{(k)}, S_j) + 0.5 p_j R_j^{(k)} - \sum_{i=1}^{26} c_j x_{ij}^{(k)} \right]$$
**全套线性化不等式组**：
$$\begin{cases} 
Q_j^{(k)} \le Y_j^{(k)} \\
Q_j^{(k)} \le S_j + 0.5 R_j^{(k)} \\
R_j^{(k)} \ge Y_j^{(k)} - S_j \\
R_j^{(k)} \ge 0, \quad Q_j^{(k)} \ge 0
\end{cases}$$

### 3. 2023-C：蔬菜商品自动定价与补货决策（稀疏统计与非线性需求曲线）
- **核心数据认知**：6 品类蔬菜日销量是稀疏时间序列，**空白数据代表未销售，坚决不填补任何数值（包括 0）**。
- **数学建模要点**：
  1. **需求-价格弹性曲线**：按周/月聚合后拟合成本加成定价弹性：
     $$D_i(P_i) = a_i \cdot P_i^{-\beta_i} \quad \text{或} \quad D_i(P_i) = a_i - b_i P_i$$
  2. **考虑损耗率的期望收益最大化**（报童模型改装）：
     $$\max_{Q_i, P_i} \mathbb{E}[\Pi_i] = P_i \cdot \min(Q_i(1 - \alpha_i), D_i(P_i)) - C_i Q_i + v_i \max(Q_i(1 - \alpha_i) - D_i(P_i), 0)$$
     其中 $\alpha_i$ 为损耗率，$C_i$ 为批发进价，$v_i$ 为打折残值。

### 4. 2022-C：古代玻璃成分分析与鉴别（成分数据单形空间 CLR 变换）
- **核心数据特性**：14 种化学成分百分比 $\sum_{j=1}^{14} x_{ij} \approx 100\%$。
- **数学建模标准流程**：
  1. **均分误差归一化**（去除严重失真样本后）：
     $$\Delta x_i = \frac{1}{14}\left(100 - \sum_{j=1}^{14} x_{ij}\right), \quad x'_{ij} = x_{ij} + \Delta x_i \implies \sum_{j=1}^{14} x'_{ij} = 100\%$$
  2. **中心对称对数比变换 (Centered Log-Ratio, CLR)**：
     将有界单形空间映射到无界欧氏实空间 $\mathbb{R}^{14}$：
     $$y_{ij} = \operatorname{clr}(x'_{ij}) = \ln x'_{ij} - \frac{1}{14} \sum_{k=1}^{14} \ln x'_{ik} \quad \left(\text{满足 } \sum_{j=1}^{14} y_{ij} = 0\right)$$
  3. **逆变换 (Inverse CLR)**：
     $$x'_{ij} = \frac{\exp(y_{ij})}{\sum_{k=1}^{14} \exp(y_{ik})} \times 100\%$$
  4. **分类与判别**：在 CLR 空间中执行主成分降维（PCA）与 Fisher 线性判别分析（LDA）。

### 5. 2021-C：生产企业原材料订购与转运（供货特征量化与动态库存规划）
- **核心指标数学公式**：
  - **总供货均值**：$\mu_j = \frac{1}{n_j}\sum_{i=1}^{240} g_{ij}$ （$n_j = \sum_{i=1}^{240} \operatorname{sign}(d_{ij})$ 为有效订货周数）
  - **全周期供货贡献率**：$G_j = \frac{\sum_{i=1}^{240} g_{ij}}{\sum_{i=1}^{240}\sum_{k=1}^{402} g_{ik}}$
  - **订货完成率**：$H_j = \frac{G_j}{n_j}\sum_{i=1}^{240} \frac{g_{ij}}{d_{ij}}$
  - **供货波动稳定性**：$\sigma_j = \sqrt{\frac{1}{n_j} \sum_{i=1, d_{ij}>0}^{240} (g_{ij} - \mu_j)^2}$
- **决策模型**：以产能消耗 $28200\text{ m}^3/\text{周}$ 和 2 周安全库存为硬约束，建立采购成本与转运损耗最小的动态规划/线性规划模型。

### 6. 2020-C：中小微企业信贷策略（违约概率机理与双目标优化）
- **信贷风险量化**：
  - 拒绝 AHP / TOPSIS 简单打分，必须通过发票数据（有效发票率、进销项差额、负废票率、增长率）结合 Logistic 回归量化**企业违约概率 $p_i$**。
- **信贷决策优化模型**：
  设 $x_i \in \{0, 1\}$ 表示是否放贷，$L_i$ 为放贷额度，$r_i$ 为年利率：
  $$\max \text{收益} = \sum_{i=1}^{n} x_i \cdot L_i \left[ (1 - p_i) r_i - p_i \cdot (1 - \text{回收率}) \right]$$
  $$\text{s.t.} \quad \sum_{i=1}^n x_i L_i \le \text{总额度 (1亿元)}, \quad L_{\min} \le L_i \le L_{\max}$$

## 三、 C 题模型与方法适用性避坑矩阵

| 任务模块 | 专家推崇的适用方法 (Recommended) | **专家明令禁止的死穴** (Prohibited) |
| :--- | :--- | :--- |
| **多指标筛选** | 业务机理分析、相关性分析、方差膨胀因子 (VIF) | 盲目直接套用 PCA 降维后丢失所有物理意义 |
| **风险与评价量化** | 真实业务机理函数、Logistic 违约概率、效用函数 | 简单套用 AHP、模糊综合评价、TOPSIS 线性加权打分 |
| **成分数据分析** | 中心对称对数比 (CLR) 变换、等距对数比 (ILR) | 直接在原始百分比数据上算欧氏距离或相关系数 |
| **连续/离散优化** | 精确数学规划 (MILP/MINLP)、精确线性化松弛 | 盲目使用遗传算法 (GA)、粒子群 (PSO)、模拟退火 (SA) |
| **小样本分类判别** | Fisher 判别分析、Logistic 回归、有序样本聚类 | 盲目套用深度神经网络、XGBoost（小样本严重过拟合） |
