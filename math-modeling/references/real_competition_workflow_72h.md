# 72小时/96小时 真实数学建模竞赛全真攻坚指南 (Real Competition Playbook)

> 本指南基于全国大学生数学建模竞赛（CUMCM）、美国大学生数学建模竞赛（MCM/ICM）顶级获奖团队（国一/高教社杯/O奖）实战经验，深度还原真实赛场的极限时间分配、三角色高效分工、评委专家评审偏好与封箱交付标准。

---

## 1. 真实竞赛全真时钟与时间表 (72h / 96h)

```
[Day 1: 破题与地基 (0~18h)]
00h~02h: 赛题通读与初筛 ──→ 02h~06h: 选题立项决策 (CP0) ──→ 06h~18h: 数据深度审计、符号系统建立与 Baseline PoC (CP1)
                                                                                 │
[Day 2: 核心攻坚与递进建模 (18~48h)]                                              ▼
18h~30h: Q1 基础模型精细化与基准建立 ──→ 30h~42h: Q2 现实条件增量改装 ──→ 42h~48h: Q3 综合决策/反事实推演 (CP2)
                                                                                 │
[Day 3: 诊断验证与论文冲刺 (48~66h)]                                              ▼
48h~56h: 时间外验证、DW自相关检验与灵敏度弹性 ──→ 56h~60h: 关键数字冻结 (CP3) ──→ 60h~66h: 论文大纲、三线表与三段式摘要精修 (CP4)
                                                                                 │
[Day 4/最后6小时: 封箱复现与终审 (66~72h)]                                        ▼
66h~69h: 干净环境全量一键复跑验证 ──→ 69h~71h: 论文规范排版 (正文18~25页/页码) ──→ 71h~72h: 匿名检查、MD5校验与打包提交 (CP5)
```

## 2. 团队三角色职责与协同协议 (Team Roles & Protocols)

数学建模不是个人的孤军奋战，而是三个角色在时间轴上的高效交织：

| 角色 | 核心职责 (Core Responsibilities) | 阶段产出物 | 绝对禁忌 (Never Do) |
|------|-----------------------------------|-----------|---------------------|
| **建模手 (队长/架构师)** | • 负责赛题数学抽象与机理推导<br>• 制定《设问递进图》与核心假设清单<br>• 统一全局变量与符号系统（`symbols.md`）<br>• 设计验证协议与敏感性分析参数 | `problem_spec.md`<br>`assumptions.md`<br>`symbols.md`<br>`model_formulation.md` | • 随意引入不切实际的离奇假设<br>• Q2 盲目推翻 Q1 造成割裂<br>• 把简单问题强行套用复杂黑盒模型 |
| **编程手 (算法/工程师)** | • 负责数据清洗与探索性分析 (EDA)<br>• 编写 Baseline 与主模型高效求解代码<br>• 约束满足性检查与求解器状态监控<br>• 生成高分辨率图表（三线表、相图、雷达图）<br>• 维护代码复现性与脚本自动化 | `00_audit.py`<br>`01_solve.py`<br>`outputs/figures/`<br>`run_summary.json`<br>`frozen_numbers.json` | • 在代码中使用 `plt.show()` 弹窗阻塞<br>• 代码路径写死绝对路径导致无法复现<br>• 伪造/手工篡改计算数字 |
| **论文手 (作家/排版师)** | • 负责论文结构布局与 LaTeX 排版<br>• 深度参与问题分析与机理叙事<br>• 撰写三段式“灵魂摘要”（每问方法+精确数字+结论）<br>• 图表排版与2-4句深度学术解读<br>• 最终格式规范与支撑材料打包核验 | `paper.tex`<br>`paper.pdf`<br>`abstract.md`<br>`supporting_materials/` | • 摘要无具体方法名和量化数字<br>• 靠加无意义大图凑页数（正文须18~25页）<br>• 泄露队员/学校等任何身份信息 |

## 3. 评委专家评审偏好与高分秘籍 (Grading Insights)

全国组委会及各赛区评阅专家每年评阅海量论文，其评审机制与打分偏好遵循以下铁律：

### 3.1 摘要是论文的“命脉” (占评分 40% 以上权重)
- **评委阅读时间**：初筛阶段每篇论文摘要仅停留 1~2 分钟。
- **高分摘要公式**：
  1. **首段（背景与定位）**：简要概括研究背景，用 1~2 句话点明核心挑战与全文建模总体框架。
  2. **中段（分问逐项剖析 - 核心得分点）**：
     - **针对问题一**：明确写出【模型名称】+【核心算法/机理】+【最终精确求解数字与单位】+【物理/经济含义】。
     - **针对问题二**：采用因果句式：“针对新增的 X 现实条件，在 Q1 的 Y 模型上引入 Z 改装，求解得到……（具体数值），相比 Q1 性能提升了……”。
     - **针对问题三/四**：给出基于模型的具体策略建议、阈值或 Pareto 方案。
  3. **末段（模型特色与稳健性）**：总结模型主要创新特色，列出敏感性分析/误差检验的具体量化范围（如“在参数波动 ±15% 下，最优解偏差保持在 3.2% 以内，证明了极高鲁棒性”）。
- **硬规范**：**严格限制在第 1 页纸以内**（300~800字），绝对禁止跨页！

### 3.2 图表“三一法则”与学术规范
- **图图有编号，表表有三线**：所有表格采用标准三线表（booktabs），图表必须有清晰标注和物理量纲。
- **图后必有 2~4 句深入解读**：严禁出现“如图1所示”后直接跳过；必须从图表曲线的拐点、极值、斜率变化中提炼出背后的数学与现实机理。
- **禁止凑图**：图表必须具有信息增量（如相平面轨线、敏感性热力图、Pareto前沿）。

### 3.3 逻辑连贯性与“拒绝拼盘”
- 评委反感将各问割裂写成三篇独立小论文。
- 必须展示 **Q1（基础基准） $\to$ Q2（增量改装） $\to$ Q3（综合决策）** 的内在演进逻辑。

## 4. 阶段攻坚全真检查清单 (Action Checklist)

### 阶段 0：选题立项 (0h~6h)
- [ ] 通读全部赛题，完成 `topic_decision.md`（按数据量、求解难度、团队擅长打分）；
- [ ] 确定赛题，记录官方所有规则（语言、提交格式、截止时区）。

### 阶段 1：数据探索与符号系统 (6h~18h)
- [ ] 原始数据只读归档至 `data/raw/`；
- [ ] 输出数据审计报告（缺失值机制、异常点、相关性矩阵）；
- [ ] 建立全局符号表 `symbols.md`，全队统一变量定义；
- [ ] 跑通 ≤30 行 Baseline PoC 代码，获取第一批基准数字。

### 阶段 2：递进建模与代码求解 (18h~48h)
- [ ] Q1 建立经典可解释模型，生成基准对照方案；
- [ ] Q2 明确新增现实条件，完成模型增量改装，做同口径对比；
- [ ] Q3 提出量化评价指标、决策方案或多情景仿真；
- [ ] 检查求解器状态（Optimal/Feasible），核查所有硬约束无一违背。

### 阶段 3：验证诊断与数字冻结 (48h~60h)
- [ ] 预测类执行时间外滚动验证；统计类执行 DW 自相关检验与残差分析；
- [ ] 计算关键参数弹性 $S = \frac{x}{y}\frac{dy}{dx}$，绘制 ±10%~±20% 敏感性波动图；
- [ ] 核心数字写入 `frozen_numbers.json`，全队核准锁定。

### 阶段 4：论文写作与排版 (60h~66h)
- [ ] 撰写 1 页三段式摘要，字数精炼、数字齐全；
- [ ] 目录单占 1 页（保留二级标题）；
- [ ] 正文页数严格控制在 18~25 页，页码从正文标 1；
- [ ] 检查所有公式有编号，重要结论有物理/经济学解释。

### 阶段 5：封箱复现与交付核验 (66h~72h)
- [ ] 在干净独立目录下执行全量一键复跑脚本，确认生成的所有图表和表格与论文数字 100% 吻合；
- [ ] 严格匿名核查（正文、页眉页脚、代码注释、PDF 元数据中无任何个人、指导教师或学校信息）；
- [ ] 支撑材料按 `supporting_materials_layout_v5_0.md` 规范打包，计算并核对 MD5 校验码。
